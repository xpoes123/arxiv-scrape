The paper found ~3 modes capture flapping and a 4th captures turning — across five individual hawks the same modes recur, only the weights differ. The tight Mode-1↔Mode-2 loop below is that efficient parametric coupling: real flight lives on a low-dimensional attractor, not a high-dim mess.

Try: drop Mode 1→0 + raise Mode 3 for a pure glide, then push Mode 4 to carve a turn.
